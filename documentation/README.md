# Documentación

Esta carpeta reúne la documentación obligatoria de la prueba técnica.

- `architecture.md`: arquitectura, capas y flujo de información.
- `domain-model.md`: agregado principal, estados e invariantes.
- `technical.md`: instalación, configuración, migraciones y ejecución.
- `operations.md`: uso funcional y casos de uso.
- `ai.md`: proveedor, prompts, controles y limitaciones.
- `testing.md`: alcance, evidencias y cobertura.
- `ai-usage.md`: uso de herramientas de IA durante el desarrollo.
- `api.md`: contrato REST implementado.
- `decisions.md`: decisiones técnicas relevantes.
- `test-cases.md`: catálogo de casos cubiertos.
- `evidence/README.md`: capturas y resultados de validación.
- `delivery.md`: checklist final y guía de revisión.
