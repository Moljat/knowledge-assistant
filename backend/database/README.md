# Database scripts

`initial-schema.sql` is generated by Entity Framework Core from the committed migrations.
It is idempotent and can be executed more than once against SQL Server.

Regenerate it after adding a migration:

```powershell
dotnet tool restore
dotnet ef migrations script --idempotent --project backend/src/KnowledgeAssistant.Infrastructure --output backend/database/initial-schema.sql
```

Do not edit the generated SQL manually. Schema changes must originate in the EF Core model
and migration history.
